Migrate a device hierarchy between tenants

This copies a group or device, everything beneath it, their external identities and optionally their measurements, events and alarms into a second tenant.

  • The source tenant is not changed. Nothing is deleted from it.
  • Objects get new ids in the target. The old ids are recorded in a mapping.
  • Everything created is marked with a run id, so this can be undone.
  • Operations are not migrated.

Both tenants must be subscribed to the migration microservice. Subscribing them is done under Tenants, not here.
